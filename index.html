Daily monitoring checklist

  • Check the number of submissions for each tool against the fieldwork plan (Data → Table in the backend).
  • Check that each record has consent recorded and no names or other identifying details.
  • Check that every [CORE] question has been answered, and follow up with interviewers on gaps.
  • Check FGD coverage: one per district, with both districts in each health zone covered.
  • Download the data and audio regularly (Data → Downloads) and store them on the encrypted study drive.
Access: Do not share this page with data collectors. They use the data collector portal, which has only the questionnaire links. Manage backend access through the project's sharing settings in KoboToolbox.
